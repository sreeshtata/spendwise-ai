Name & Small Description

Name: SpendWise AI — Smart Spending Assistant

Small Description: An independent, PayPal-connected personal financial copilot designed to empower consumers to make disciplined, highly informed purchasing decisions. SpendWise AI brings together deterministic monthly envelope budgeting with strict essential living constraint protections, true multi-merchant delivered cost comparisons, seamless PayPal Sandbox test checkout, and privacy-preserving peer spending intelligence.

2

Problem You Tried to Solve

Consumers navigate personal finances and online commerce through fragmented, adversarial systems that actively work against long-term financial health:

1. Opaque True Delivered Costs E-commerce sticker prices routinely hide mandatory delivery fees, local taxes, and payment surcharges until final checkout, causing unplanned budget overruns.
2. Unrealistic or Destructive Budgeting Traditional budgeting apps either act as passive historical rear-view mirrors or recommend naive mathematical cuts that silently slash non-negotiable essentials like rent and groceries.
3. Isolated Purchasing Disconnected From Budgets Shopping and budgeting live in separate worlds. Shoppers cannot evaluate how a specific purchase immediately impacts their remaining monthly category allocation before committing.
4. Lack of Contextual Peer Benchmarking Consumers struggle to evaluate if their spending is normal without reliable, privacy-guaranteed benchmarks ($k$-anonymity) from verified peer cohorts.
3

The Best Solution You Have Come Up With

We engineered a unified three-feature financial architecture centered on a single source of truth and integer minor-unit accounting:

Feature 1: Smart Budget Plans Deterministic envelope calculations combined with structured AI optimization. Strictly preserves non-negotiable essential living minimums (rent, groceries, basic utilities) and explicitly flags infeasible shortfalls without silent cuts.
Feature 2: Smarter Product Search Deep merchant offer comparison showing complete delivered price breakdowns (item + shipping + tax - verified coupons) alongside instantaneous remaining budget impact calculations and PayPal Sandbox checkout.
Feature 3A: Peer Spending Context Strict privacy-preserving cohort analysis ($k \ge 30$ threshold). Suppresses benchmarks if participant count is under 30 to prevent re-identification, presenting truthful contextual medians.
Feature 3B: My Spending Progress Meaningfully aligned historical period comparisons (prior month, prior year month, prior year YTD) tracking exact expenditure changes, category shifts, and percentage point improvements in savings rate.
Zero Float Guarantee: Every monetary value across the database, APIs, and business logic is handled strictly in integer minor units (paise/cents) — eliminating IEEE-754 floating-point drift ($₹0.10 + ₹0.20 = ₹0.30$ exactly).

How You Created the Solution (App / Web / AI Architecture)

1. Web Application (Frontend) Built with React 18 TypeScript Vite Tailwind CSS. Featuring rich data tables via AG Grid Community and comparative financial visualizations via Recharts. Server state managed reactively via TanStack Query.
2. API & Ledger Engine (Backend) Powered by Node.js Express Zod. Single-source-of-truth financial calculation service guaranteeing exact accounting rules, user ownership validation, CSV formula injection defense, and OpenAPI contract documentation.
3. AI & Rules Engine Dual-engine intelligence: deterministic verified rules engine for baseline feasibility, paired with structured generative AI for contextual explanations, budget rebalancing proposals, and actionable trade-off advice.
4. Integrations & Demonstrations PayPal Sandbox order creation and idempotent capture workflow; Channel3 verified product and merchant discovery; Elasticsearch transaction search with automatic PostgreSQL fallback.
